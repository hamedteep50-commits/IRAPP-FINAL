نسخه یکپارچه IRAPP 3.0.0

این بسته برای ساخت یک APK واحد آماده شده است.
مشکل دکمه‌ها با حذف رویکرد قبلی اجرای دوباره onclick و جایگزینی آن با event delegation مرکزی در index.html بازطراحی شده است.
خودرویار ۲۰۰ در همان برنامه و همان نصب قرار گرفته و داده‌های vehicles/parts/faults/dtc و سایر داده‌های موجود پروژه در assets/data قرار دارند.
HAMED AI در همان برنامه قرار دارد و رابط آن برای اتصال بعدی به Server/API آماده است.

ساخت:
GitHub Actions -> Build IRAPP Unified Final APK -> Run workflow
سپس Artifact با نام IRAPP-UNIFIED-FINAL-APK را دریافت کنید.

نکته: سرور واقعی، حساب ابری، درگاه پرداخت و انتشار فروشگاهی بدون مشخصات سرویس/کلیدهای واقعی قابل فعال‌سازی نهایی نیستند؛ این بسته رابط و معماری اولیه آنها را یکپارچه کرده است.

نسخه 3.3.0: اصلاح رویداد لمس/کلیک، افزودن مرکز کاربر، پنل مدیریت رابطی، راهنما و بروشور، کیف پول/کارت بانکی محلی، درآمد و اشتراک‌گذاری Android.
