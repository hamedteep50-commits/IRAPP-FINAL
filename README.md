# IRAPP Super Platform 4.1.0 — Web/PWA

این پوشه یک پوستهٔ Web/PWA مستقل از هستهٔ Android ارائه می‌کند تا رابط و منطق اولیهٔ IRAPP در مرورگر و دستگاه‌های مختلف قابل اجرا باشد.

## مسیر چندسکویی
- Android / Tablet: ماژول Android موجود در `app/`
- Web / PWA: همین پوشه
- iOS / iPadOS / Windows / macOS / Linux: این نسخه معماری و رابط مشترک را آماده می‌کند؛ بسته‌های native نهایی این سکوها باید در مرحلهٔ انتشار با ابزار/SDK رسمی هر سکو ساخته و تست شوند.

## نکته
Backend واقعی، احراز هویت، چت، پرداخت، انتشار APK و همگام‌سازی ابری هنوز باید به API امن متصل شوند؛ اطلاعات آزمایشی محلی به‌عنوان سرویس واقعی معرفی نشده‌اند.
